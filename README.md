# City Digital Twin Ontology

The City Digital Twin project at the University of Toronto's Urban Data Research Centre develops a standards-based knowledge graph for City of Toronto data.

This repository is organized primarily by subject/domain.

## Active domains

- `Administrative Areas/`
- `Buildings/`
- `Census/`
- `Services and Amenities/`

## Shared and project material

- `Housing Potential Project/` - historical Housing Potential work, including the Road Network.
- `OWL/` - shared ontology files pending migration to the proposed `Ontologies/` structure.
- `Documentation/` - project-wide documentation.
- `Toronto Common Data Model/` - project-level TCDM documentation pending consolidation under Documentation.

The repository is being reorganized incrementally so existing work can be preserved and reviewed before obsolete duplicate locations are removed.

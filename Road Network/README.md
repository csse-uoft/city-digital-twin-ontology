# Road Network

This folder contains the active Road Network work for continued City Digital Twin development.

The Road Network is maintained here as a current domain, while the copy under `Housing Potential Project/Road Network/` is preserved as a historical snapshot of the Housing Potential project.

## Contents

- **Mappings/** - ORN mapping documentation and source-data description.
- **Scripts/** - the active ORN-to-RDF transformation script.
- **Diagrams/** - Road, RoadLink, Junction, and Road Network diagrams.
- **Ontologies/** - ISO/IEC ontology references used by the Road Network work.

## Historical copy

Do not use `Housing Potential Project/Road Network/` as the primary location for continued Road Network development. That folder is retained to preserve the historical Housing Potential project structure.
